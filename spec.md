# Trajectory_Recon 模組開發規格書
**File:** `Trajectory_Recon.py`  
**Purpose:** 修復航程資料中存在時間缺口 (`R5_missing_time_gap`) 的 AIS 航跡。

---

## ### TASK
Implement a Python module `Trajectory_Recon.py` that reconstructs vessel trajectories
for voyages marked as `invalid_reason = "R5_missing_time_gap"`.

The reconstruction should handle three levels of missing time gaps:
1. `small_time_gap` → between **0.5 and 1.5 hours**
2. `mid_time_gap` → between **1.5 and 3 hours**
3. `large_time_gap` → greater than **3 hours**

---

## ### INPUT

The module will use:
- `voyage_merged`: a DataFrame produced by `voyage_splitter.py`, containing:
  - `voyage_id`: int — voyage identifier  
  - `invalid_reason`: str — QA reason (if `"R5_missing_time_gap"`, the voyage requires reconstruction)  
  - `gap_list`: list of dictionaries, each describing one missing segment  

Example structure of `gap_list`:
```python
[
  {
    "gap_type": "small_time_gap" | "mid_time_gap" | "large_time_gap",
    "gap_hr": float,
    "A_idx": int,
    "B_idx": int,
    "A": {"lat": float, "lon": float, "t": Timestamp},
    "B": {"lat": float, "lon": float, "t": Timestamp}
  },
  ...
]

### OUTPUT

The module should output a reconstructed DataFrame that contains all points from the original voyage,
plus newly generated points filling in the time gaps.

Output columns:
| Column                 | Type     | Description                                            |
| ---------------------- | -------- | ------------------------------------------------------ |
| `voyage_id`            | int      | Voyage identifier                                      |
| `Lat`, `Long`          | float    | Geographic coordinates                                 |
| `Timestamp`            | datetime | Timestamp for the point                                |
| `Reconstruction`       | bool     | True if generated by reconstruction, False if original |
| `gap_type`             | str      | Type of gap the point belongs to                       |
| `source_A`, `source_B` | dict     | Optional references to gap endpoints (debug)           |

### LOGIC

1. Voyage Selection

Select all voyages from voyage_merged where invalid_reason == "R5_missing_time_gap".

For each voyage, extract its gap_list.

2. Gap Type Dispatch

For each gap in gap_list, determine its gap_type:

small_time_gap → use A* path interpolation.

mid_time_gap or large_time_gap → use seabed-grid (海骨圖) + A* combined reconstruction.

3. Reconstruction Methods

Both methods take endpoints A and B as inputs.

Generate intermediate points (Lat, Long, Timestamp) between A and B.

The number of generated points can depend on time gap length or a fixed resolution.

Insert reconstructed points into the voyage between A and B.

Mark all inserted points with Reconstruction=True.

4. Integration

Merge the reconstructed points into the original voyage trajectory.

Sort by Timestamp to maintain time order.

If a voyage contains multiple gaps, reconstruct each gap sequentially in ascending order of A_idx.

Preserve all original points (Reconstruction=False).

5. Output

Return or save a unified DataFrame containing:

All voyages (including repaired ones).

Each voyage is now continuous with no large time gaps.

Optionally, save the result as Reconstructed_Voyages.csv.

### RECONSTRUCTION RULES

| Gap Type       | Duration Range | Algorithm        | Notes                                            |
| -------------- | -------------- | ---------------- | ------------------------------------------------ |
| small_time_gap | 0.5–1.5 hr     | A*               | fine-grained interpolation                       |
| mid_time_gap   | 1.5–3 hr       | seabed-grid + A* | balance between accuracy & cost                  |
| large_time_gap | >3 hr          | seabed-grid + A* | allow wider search radius, coarser interpolation |

### EXTRA RULES

- Time interpolation should be linear between A and B.

- Ensure reconstructed path does not overlap land (landmask filtering optional).

- If A* fails, skip that gap and log an error message.

- Reconstructed points must not break chronological order.

- If a voyage contains multiple gaps, repair them one by one and append all results

### FINAL GOAL

Trajectory_Recon.py should:

- Automatically fix all voyages with R5_missing_time_gap issues.

- Produce a continuous, cleaned, and timestamp-consistent trajectory dataset.

- Mark all reconstructed points clearly for downstream ETA model training or visualization.
